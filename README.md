# DataShare CLI — Неделя 1

Консольное приложение на современном JavaScript (ES6+), запускаемое через Node.js.
Первая практическая работа в 8-недельном проекте **DataShare**: фундамент
JavaScript → Node.js → REST → MongoDB → Mongoose → авторизация → real-time → тестирование.

- **Студент:** Аделканов Рауат
- **Группа:** CS-302(с)
- **Вариант:** 2 — Книги
- **Дисциплина:** Веб-программирование на JavaScript

## Описание

Приложение работает с массивом объектов-книг, имитирующим будущую базу данных.
Реализованы просмотр всех записей, поиск по id, фильтрация по категории,
поиск по ключевому слову (в названии и описании, без учёта регистра), создание
и удаление записей, а также статистика (общая и средняя стоимость, статистика
по категориям). Загрузка данных имитирует асинхронный запрос к серверу
через `Promise` и `async/await` с обработкой ошибок `try/catch`.

## Реализованные функции

### `src/services/itemService.js`

| Функция                           | Что делает                                                                      |
| --------------------------------- | ------------------------------------------------------------------------------- |
| `getAllItems(items)`              | Возвращает копию массива всех записей                                           |
| `getItemById(items, id)`          | Возвращает одну запись по id или `null`                                         |
| `createItem(items, data)`         | Создаёт новую запись (id генерируется, `createdAt` проставляется автоматически) |
| `deleteItem(items, id)`           | Возвращает новый массив без записи с указанным id                               |
| `findByCategory(items, category)` | Фильтрует записи по категории без учёта регистра                                |
| `calculateTotalPrice(items)`      | Считает общую стоимость через `reduce`                                          |
| `calculateAveragePrice(items)`    | Считает среднюю цену записи                                                     |
| `searchItems(items, query)`       | Ищет по `title` и `description` без учёта регистра                              |
| `getItemTitles(items)`            | Возвращает список названий через `map`                                          |
| `getCategoryStats(items)`         | Группирует записи по категориям и считает суммы через `reduce`                  |
| `loadItems(items, delayMs)`       | Асинхронно «загружает» данные (имитация сервера через `setTimeout`)             |

| ------------------------- | ------------------------------------------------------------- |

## Контрольные вопросы и ответы

**1. Что такое Node.js и чем он отличается от JavaScript в браузере?**

Node.js — это среда выполнения JavaScript вне браузера, построенная на движке V8.
В браузере JS работает со страницей (DOM, `window`, `document`) и не имеет доступа
к системе. В Node.js нет DOM, но есть доступ к файловой системе (`fs`), процессам
(`process`), сети и другим возможностям ОС — поэтому на нём пишут серверы и
консольные программы, такие как этот проект.

**2. Для чего нужен npm?**

npm (Node Package Manager) — менеджер пакетов Node.js. Он устанавливает сторонние
библиотеки (`npm install`), управляет зависимостями и их версиями, запускает
скрипты проекта (`npm start`) и позволяет публиковать собственные пакеты.

**3. Что хранится в package.json?**

Манифест проекта: название, версия, описание, автор, точка входа (`main`),
тип модулей (`type`), скрипты (`scripts`) и списки зависимостей
(`dependencies`, `devDependencies`).

**4. Зачем нужен type: module?**

Он включает в Node.js поддержку ES Modules — синтаксиса `import` / `export`.
Без `"type": "module"` Node.js по умолчанию использует CommonJS
(`require` / `module.exports`), и `import` выдаст ошибку.

**5. Чем const отличается от let?**

Обе переменные имеют блочную область видимости, но `const` нельзя переприсвоить
после объявления, а `let` — можно. Важно: у `const`-объекта можно менять
содержимое (свойства, элементы), запрещено только присваивание новой ссылки.
По умолчанию используют `const`, а `let` — только когда нужно переприсваивание
(например, `let items` в `index.js`, потому что массив обновляется после
создания и удаления записей).

**6. Почему в современном коде стараются не использовать var?**

У `var` функциональная, а не блочная область видимости; объявление «всплывает»
(hoisting), поэтому переменную можно использовать до объявления; `var` позволяет
повторно объявить ту же переменную. Всё это провоцирует трудноуловимые ошибки.
`let` и `const` лишены этих проблем.

**7. Что такое стрелочная функция?**

Короткий синтаксис объявления функции: `(a, b) => a + b`. У стрелочной функции
нет собственных `this` и `arguments` — они берутся из внешнего контекста.
Удобна для колбэков и коротких функций. Пример из проекта:
`const getAllItems = (items) => [...items];`

**8. Что такое destructuring?**

Деструктуризация — извлечение значений из объекта или массива в отдельные
переменные одной конструкцией: `const { title, price } = item;` или
`const [first] = arr;`. В проекте используется в `formatItem`, в параметрах
`map(({ id }) => id)` и в цикле `for (const [category, { count }] of ...)`.

**9. Что делает spread operator?**

Spread (`...`) «раскладывает» массив или объект на отдельные элементы.
Используется для копирования и объединения: `[...items]` — копия массива,
`{ ...data, createdAt: ... }` — новый объект с полями `data` плюс новые поля,
`Math.max(...ids)` — передача элементов массива как аргументов.

**10. Чем spread отличается от rest?**

Синтаксис одинаковый (`...`), разница в направлении работы. Spread
**раскладывает** коллекцию на элементы (в литералах и вызовах функций).
Rest **собирает** оставшиеся элементы в массив (в параметрах функции:
`printLines(...lines)` принимает любое число аргументов, и при деструктуризации).

**11. Что такое template literal?**

Шаблонная строка в обратных кавычках с интерполяцией выражений через `${...}`
и поддержкой многострочности: `` `${title} — ${author}, ${year} г.` ``.
Все сообщения программы построены на шаблонных строках.

**12. Что делает optional chaining ?.?**

Оператор `?.` безопасно читает вложенное свойство: если объект слева —
`null` или `undefined`, выражение возвращает `undefined` вместо ошибки.
Пример из проекта: `item?.series?.name` — не упадёт, даже если у книги
нет поля `series`.

**13. Чем ?? отличается от ||?**

`??` возвращает правый операнд только когда левый — `null` или `undefined`.
`||` — когда левый любой falsy (`0`, `""`, `false`, `NaN`, `null`, `undefined`).
Поэтому для значений по умолчанию безопаснее `??`: например, `0 ?? 5` даст `0`,
а `0 || 5` — `5`, что может быть ошибкой.

**14. Что делает map()?**

`map()` преобразует каждый элемент массива функцией-колбэком и возвращает
**новый массив той же длины** с результатами. Пример:
`items.map(({ title }) => title)` — массив названий всех книг.

**15. Чем filter() отличается от find()?**

`filter()` возвращает **массив всех** элементов, прошедших условие (может быть
пустым). `find()` возвращает **первый** подходящий элемент или `undefined`,
если ничего не нашлось. В проекте: `findByCategory` использует `filter`,
а `getItemById` — `find`.

**16. Для чего используется reduce()?**

`reduce()` сворачивает массив в одно итоговое значение, последовательно
накапливая результат в аккумуляторе: сумма, объект, статистика. Пример:
`items.reduce((total, { price }) => total + price, 0)` — общая стоимость,
где `0` — начальное значение аккумулятора.

**17. Что такое Promise?**

Promise (промис) — объект, представляющий результат асинхронной операции,
которая завершится в будущем. Имеет три состояния: `pending` (выполняется),
`fulfilled` (успешно, вызван `resolve`) и `rejected` (ошибка, вызван `reject`).
Пример из проекта: `delay` в `helpers.js` — промис-обёртка над `setTimeout`.

**18. Зачем нужен async/await?**

Это синтаксический сахар над промисами. `async` делает функцию возвращающей
промис, а `await` приостанавливает выполнение функции до завершения промиса,
не блокируя поток. Асинхронный код выглядит как обычный последовательный:
`let items = await loadItems(initialItems, 1500);` в `index.js`.

**19. Зачем используется try/catch при асинхронных операциях?**

Если промис завершился с ошибкой (`rejected`), `await` выбрасывает исключение.
`try/catch` позволяет поймать его и обработать (показать сообщение, повторить
попытку), чтобы программа не завершилась аварийно. В проекте это показано
в `main()`: вызов `loadItems(null, 500)` специально генерирует ошибку,
которая корректно перехватывается.

**20. Почему код лучше разделять на модули?**

Каждый файл отвечает за свою задачу: `items.js` — данные, `itemService.js` —
логика, `helpers.js` — утилиты, `index.js` — запуск и вывод. Такой код проще
читать, тестировать, переиспользовать и изменять, а зависимости явно видны
через `import`/`export`. На следующих неделях эти же модули будут перенесены
в Express и MongoDB без переписывания всего проекта.
